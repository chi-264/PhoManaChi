Milestone: Storage analysis and safe cleanup

- Choose an Android folder, individual documents, or permitted media collections to scan.
- Browse file categories and logical sizes, search locations/names, sort results, and filter files of at least 100 MiB.
- Compare same-size files using streamed SHA-256 and browse verified duplicate groups.
- Cancel scans and review partial coverage and provider warnings without automatic deletion.
- Select up to 100 files, keep a verifiable copy of each known duplicate group, and review exact targets before confirming permanent deletion.
- Recheck file identity/content, access, and retained copies after Android authorization and before each deletion.
- Review per-file confirmed, skipped, failed, and unverified outcomes. Confirmed deleted logical bytes remain separate from observed internal free-space change.
- Require a fresh scan before another cleanup and preserve recorded cleanup outcomes across process restart without automatically retrying.

Scanning is limited to chosen/permitted scopes, 5,000 files, 1,000 directories, and depth 32. Private app data and directory deletion are excluded. Android provider APIs cannot make content checking and deletion atomic. This is permanent deletion, without an app recycle bin.

Use the same signing key as prior milestones. Physical-device/provider validation and the complete installed v0.3.0 → v0.4.0 update still need acceptance on the target Realme and TECNO phones.
