Milestone: App management and device capabilities

- Browse real applications visible to Phone Manager in the current Android profile.
- Search by name or package, filter user/system apps, and sort by name, package, or latest update.
- Review version, installation/update dates, installer, target API, APK-file size, and Android-reported permission grant flags.
- Open Android app settings and refresh app information when returning.
- Review an app before requesting Android's uninstall confirmation. Native checks protect Phone Manager, system/core apps, active device administrators, and default home/phone/messaging/keyboard apps.
- Recheck the reviewed package version and update time before uninstall. A changed target requires another review.
- Distinguish requested, canceled, blocked, failed, unverified, and verified uninstall results. Verification requires Android's success result and a follow-up package check.
- View current access/capability states in More → Permissions, with settings shortcuts and refresh on resume.

Package visibility is limited by Android. APK-file size excludes app data and cache. No broad package visibility, private app-data access, silent uninstall, or process termination is added.

Use the same signing key as v0.2.0. Publishing this milestone allows v0.2.0 devices to discover the update; downloading and installation still require the user's confirmation.

Physical-device validation and the complete v0.2.0 → v0.3.0 update flow remain required on the target Realme and TECNO phones.
