Milestone: Direct APK updates

- Check for new milestones in More → App updates.
- Optionally enable Android notifications for new milestones.
- Review release notes before choosing to download an APK.
- Verify download size, SHA-256, package identity, version, and the installed app's signing certificate.
- Open Android's permission and installation prompts; nothing is installed silently.
- Keep the device-monitoring tools available offline.

Install this updater-enabled build once to receive future milestones. Earlier builds do not include an update checker.
Background checks run about every six hours and can be deferred by Android. Notifications require permission.

Physical-device update installation and notification tests are still required on the target Realme and TECNO phones.
